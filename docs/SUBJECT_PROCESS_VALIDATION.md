# Automatic subject processing — 2.2.23

With Use main subject checked (either subject mode), Process image runs subject inference only if the current image has no selection, then Auto analysis when enabled, then drawing-plan generation. The separate Find main subject button remains available for inspecting/replacing the selection first. AI and manually edited masks are reused on reprocessing; changing images resets the mask. Full-image mode never requests subject inference. Cropping remains manual.

Model errors keep the plan unavailable and preserve the selected subject mode. They do not silently switch to full-image drawing. Processing rejects starts during an active operation, manual selection or Stop cleanup. Subject application returns whether its following Auto analysis actually completed; cancellation in that stage prevents the original Process click from continuing afterward. Stop, image/settings changes and disabling subject mode still invalidate late model results through the existing generation/signal checks.

The reported Extension context invalidated error is handled centrally in the studio's status display. Instead of appending Browser-mode or model-setup advice, it tells the user to refresh the game tab or reopen the large extension viewer to reconnect. This is guidance, not an automatic page refresh or a claim that changing line detection repairs an expired extension. [Chrome documents](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#when-to-reload-the-extension) that content-script changes require reloading the extension and host page.

Browser checks exercise a single Process click through real local foreground inference into a plan, model failure without a full-image fallback, existing AI/manual mask reuse, fresh image detection, unchecked full images, retained crop, and Stop during inference and the following Auto analysis. Delayed responses are released after cancellation to verify that plan generation does not resume. An explicit restart succeeds afterward. Two failure fixtures simulate an invalid extension context during the metadata-storage read and during subject inference, checking reconnect guidance and absence of the Browser-mode hint.
