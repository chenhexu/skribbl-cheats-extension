Checking Chrome GPU support…

The models and their code are included with this extension. Loading them takes time once per browser session; the public word bank is already precomputed. Keep playing in your Skribbl tab after setup.

If your service is already running, just click Check terminal service. Otherwise use the companion source project containing ai-service/start.ps1; the extension ZIP alone does not contain Python. Read the setup instructions.

  1. Open PowerShell in that project folder.
  2. Run the command below. The setup switches install the required dependencies and missing models.
  3. Keep that service running, then click Check terminal service.
powershell -NoProfile -ExecutionPolicy Bypass -File .\ai-service\start.ps1 -Setup -SubjectSetup -SearchSetup

Endpoint: http://127.0.0.1:8765. Python can also use a CUDA GPU when installed; otherwise it uses the CPU. Closing its terminal stops the service.
